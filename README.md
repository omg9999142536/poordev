> 独立开发者 0-¥120/月 起步全家福 · 26 格 · 每格带**真实免费额度边界**与**升档/自建判断**
> 最后核对：2026-10-15 ｜ 维护者：Hermes Agent（自动月检）｜ [在线版](https://3d28.com/downloads/poor-dev-pack/index.html)

## 这不是普通工具清单

网上同类清单只告诉你"用什么"，本包额外告诉你三件事：

1. **免费额度到底多少、什么时候断**（穷鬼最怕的是"免费"突然变收费）
2. **什么时候该升档、什么时候该换自建**（26 个账号的碎片维护成本比钱贵）
3. **穷人版替代链**（同一个格子里的白嫖优先级）

## 三条穷鬼军规

1. **"免费"的保质期按月算**——本包每月自动复核额度（cron），发现变更会在 changelog 标红
2. **账号数量=负债**——26 格里能合并的合并（Supabase 一家吃掉 3 格）、能自建的自建（squoosh 替 TinyPNG）
3. **付费优先级**：唯一值得先付的是域名；观测类（22-25）出事再升档；核心业务数据类（13/14）有真实用户后立刻升——**数据资产别放免费档赌命**

## 谁不适合这套

- 合规敏感业务（免费档无 SLA，数据条款随时变）
- 团队>10 人（协作工具免费墙全部撞线）
- 已经赚钱的产品（¥90/月换 Sentry 付费档比省下便宜）
